## Animation & UX Expectations (Very Important)

Use **Framer Motion** heavily but **tastefully**.

### Animation Principles
- Animations should guide attention, not distract
- Use easing curves (easeInOut)
- Short durations (0.3s – 0.6s)
- Prefer opacity + translate over scale abuse

### Required Animations
- Hero text fade + slide on load
- Section reveal on scroll
- Card hover effects (lift + glow)
- Button hover micro-interactions
- Smooth page transitions
- Lazy-loaded sections

### UX Focus
- Instant visual feedback
- Smooth scrolling
- Accessible contrast ratios
- Keyboard-friendly navigation
- Touch-friendly buttons
- Zero layout shifts

---

## Responsiveness Requirements

The portfolio **must be fully responsive**.

Breakpoints:
- Mobile (primary)
- Tablet
- Laptop
- Desktop (large screens)

Rules:
- Mobile-first CSS
- Grid-based layout
- No horizontal scrolling
- Cards stack vertically on small screens
- Navigation collapses into animated menu on mobile
